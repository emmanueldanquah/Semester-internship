# Calculator Projects| For understanding the manipulation of DOM.
A clean, responsive, and functional web-based calculator built to handle fundamental arithmetic operations.
## Features
* **Core Arithmetic : * Supports addition, subtraction, multiplication and division.
*  ** Modern UI :** One-click clear functionality ('C') to reset the calculation state easily.
*  **Floating Point  Support:** Handles decimal computations seamlessly.

  ## tech Stack
  * **HTML:** For semantic structure.
  * **CSS3:** For modern layout design and responsiveness.
  * **JavaScript (ES6):** For Core logic, computing processing, and dynamic DOM updates
##  How to Run This Project Locally

To check out the project on your machine, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the directory:**
   ```bash
   cd Calculator
   ```
3. **Open the application:**
   Simply double-click the `index.html` file to launch it in your favorite browser.
